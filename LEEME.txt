CONSULTA DE FALLAS KOMATSU 930E-2 · SACC

Actualización para GitHub Pages

1. Descomprimir el ZIP en el celular.
2. Abrir el repositorio de consulta de fallas en GitHub.
3. En Code, usar Add file > Upload files. Si no aparece, activar Sitio de escritorio en Chrome.
4. Seleccionar los archivos de la raíz, incluido LEEME.txt. No subir el ZIP.
5. Confirmar con Commit changes, en la rama main.
6. Subir los nueve PDF dentro de la carpeta manuales del repositorio. Si no existe, crear manuales/LEEME.txt mediante Add file > Create new file y confirmar. Luego abrir manuales > Add file > Upload files y seleccionar los nueve PDF de la carpeta manuales descomprimida.
7. En Settings > Pages, seleccionar Deploy from a branch, main y /(root), y guardar. Si ya está configurado así, conservarlo.
8. Abrir el enlace que GitHub muestre cuando termine la publicación.

Prueba: 2/1, 02/1 y 002/1 deben mostrar los cuatro subíndices del código 002 y resaltar el primero en amarillo. El subíndice selecciona el detalle de la guía del Excel. Los subcódigos que aparezcan dentro del texto de detección se conservan como información original.

Si buscas solo 2, 02 o 002, aparecen todos los detalles sin seleccionar uno.
Favoritos e historial se guardan en cada dispositivo.
La documentación incluida aplica al proyecto 930E-2 y conserva los alcances indicados en cada manual.
